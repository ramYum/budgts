# Budget Tracker

A personal budget tracking app — an installable PWA backed by Supabase, syncing
across phone and desktop. Categories, budgets vs actual, recurring bills,
savings goals; manual entry now, email-notification and receipt-photo ingestion
later.

## Getting started

```bash
cp .env.local.example .env.local   # then fill in Supabase + DB values
npm install
npm run dev                        # http://localhost:3000
```

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Dev server |

## Status

Phase 0 (scaffold) complete. Phase 1 (core budgeting slice) is designed in
`docs/specs/` and not yet implemented.
